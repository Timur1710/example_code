# Структура справки

Эта папка содержит все файлы, необходимые для системы справки приложения.

## Компоненты

### Основной компонент страницы справки
**Путь:** `/src/pages/HelpPage.vue`

Главный Vue компонент, отвечающий за отображение справки.

### Файл экспорта данных справки
**Путь:** `/src/shared/constants/help-files/index.ts`

Экспортирует и индексирует все файлы справки для быстрого доступа.

### Содержимое справки
**Путь:** `/src/shared/constants/help-files/md`

Содержит markdown-файлы со справочной информацией. Каждый файл содержит информацию для отдельного раздела проекта.

### Изображения для справки
**Путь:** `src/shared/constants/help-files/md_img`
Содержит изображения, используемые в файлах справки. Директория структурирована по разделам проекта.

### Примеры заполнения markdown-файлов

При создании файлов справки используйте следующие примеры форматирования:

**Заголовок раздела:**
```markdown
##### Строковый ID {.md_header}
```
- `{.md_header}` — класс CSS для стилизации заголовка (обязательный)

**Параграф с якорем:**
```markdown
id для совместимости систем {#materials_strokoviy_id}
```
- `{#materials_strokoviy_id}` — уникальный индификатор-якорь для быстрого перехода (обязательный)

**Изображение:**
```markdown
![Alt text](/img/md_img/materials/chart.jpg){.md_img}
```
- `{.md_img}` — класс CSS для форматирования изображения (обязательный)
- `{.img-left}` — класс CSS для выравнивания изображения слева
- `{.img-right}` — класс CSS для выравнивания изображения справа
- `{.img-center}` — класс CSS для выравнивания изображения по центру
- `{width=200}` — атрибут для установки ширины изображения в пиксели

**Примеры использования:**
```markdown
![Alt text](/img/md_img/materials/chart.jpg){.md_img .img-left}
![Alt text](/img/md_img/materials/chart.jpg){.md_img .img-right width=200}
![Alt text](/img/md_img/materials/chart.jpg){.md_img .img-center}
```

Для более подробной информации о форматировании markdown обратитесь к [официальной документации](https://www.markdownguide.org/).

**Важные требования:**
- Класс заголовка `{.md_header}` и уникальный якорь параграфа `{#...}` обязательны для каждого раздела
- Между текстом параграфа и изображением необходимо оставить пустую строку для корректного отображения
- Все изображения должны находиться в папке `/public/img/md_img` в соответствующем подразделе   

### Компонент иконки справки для быстрого перехода

**Путь:** `/src/shared/ui/InfoIcon/InfoIcon.vue`

Компонент отображает интерактивную иконку, которая позволяет пользователям быстро переходить к нужной справке.

**Пример использования:**
```vue
<InfoIcon 
  text="id для совместимости систем" 
  :hash="'#materials_strokoviy_id'" 
  :section="'materials'" 
/>
```

**Свойства компонента:**
- `text` — краткое описание справки (строка, обязательное)
- `hash` — уникальный якорь-идентификатор параграфа справки (строка, обязательное)
- `section` — раздел проекта (строка, обязательное)

**Доступные разделы:**
- `streams`
- `operations`
- `orders`
- `workers`
- `materials`
- `equipments`
- `directories`

**Важно:** все три свойства обязательны для корректной работы компонента.
